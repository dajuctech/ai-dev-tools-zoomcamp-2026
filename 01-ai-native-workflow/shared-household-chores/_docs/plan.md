# Product Plan: Shared Household Chores

## Product

Shared Household Chores is a small Django web application that helps people living together track household chores, assign responsibility, and see what is complete.

## MVP Features

1. Household members
   - Add household members by name.
   - Use members as chore assignees.

2. Chore management
   - Create chores with title, optional description, optional assignee, and optional due date.
   - Edit existing chores.

3. Completion tracking
   - Mark chores as complete.
   - Store completion timestamp.

4. Review views
   - Show pending chores on the main page.
   - Show completed chores separately.

## Out of Scope

- Authentication
- Recurring chores
- Notifications
- Calendar integrations
- Mobile app
- Advanced permissions
