# Product Plan: RetroLoop

RetroLoop helps teams collect weekly project feedback and run a focused retrospective.

## MVP

1. Simple accounts
   - Register with username, display name, and password.
   - Log in and log out.
   - No email verification or password reset.

2. Project and feedback cycle
   - Create a project.
   - Create a feedback cycle for the project.
   - Submit start / stop / continue feedback.

3. Retrospective board
   - Reveal feedback at the same time.
   - Group feedback into clusters.
   - Allow cluster titles to be edited.

4. Voting and summary
   - Each user has three votes.
   - Multiple votes on one topic are allowed.
   - Voting results are visible after voting closes.
   - Capture decisions and action items.

5. Transcript processing
   - Paste transcript text after the meeting.
   - Extract candidate decisions and action items using simple text rules for the MVP.

## Out of Scope

- Email authentication
- Built-in meeting recording
- Long-term media storage
- Heavy background workers
- Production deployment
